# Bomberman JS remake

_This is a work in progress_

Single player JavaScript remake of Bomberman game for NES console (1983) using HTML5 canvas.

## Setup

Navigate to cloned repo's directory and run:

```
npm install
```

To run dev server

```
npm run start
```

To build app

```
npm run build
```

## Tests

Run the unit and browser-entry smoke tests with Mocha:

```
npm test
```

Check source coverage (minimum 80% lines, 65% branches, and 70% functions):

```
npm run coverage
```

Lint test files with:

```
npm run lint:test
```

## Controls

- ⏎ - start
- 🡄 🡆 🡅 🡇 - walk
- Ctrl - plant bomb
